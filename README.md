# SALT Logo Studio

A single-file, no-build logo explorer for SALT, a small home church.
Six steps: name, style, symbol, type, colour, then test & export as PNG.

Open `index.html` in any browser, or use the live page:
https://richardbolland.github.io/salt-logo-studio/

## Editing
Everything lives in `index.html`. The lists at the top of the `<script>` hold the
fonts, palettes, icons, taglines and acronym ideas; each logo style is one
`draw()` function in `STYLES`.
